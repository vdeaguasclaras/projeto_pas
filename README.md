# Projeto PAS — Sistema PAS Marista

Protótipo navegável do Sistema PAS Marista (simulados no formato PAS/UnB): painel de coordenação, textos-base com alocação de itens por slots, editor de itens com revisão comentada, caderno de provas, cartão-resposta e correção/boletins.

- `app/` — aplicação React + Vite + TypeScript com o redesign "Ar & Luz" (handoff do Claude Design). Para rodar: `cd app && npm install && npm run dev`.
- `PLANO.md` — plano de implementação do app híbrido (fase online de geração da prova + fase offline de leitura óptica/correção).
- `prototipo-pas-marista.html` — protótipo v2, arquivo único (HTML/CSS/JS inline). Referência de conteúdo/fluxo; abra direto no navegador.

Fonte do protótipo v2: recuperado do artifact "Protótipo — Sistema PAS Marista" publicado no claude.ai (atualizado em 17/07/2026).
